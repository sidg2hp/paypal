# PayPal Sandbox evidence

This folder is for **real** PayPal Sandbox evidence generated by
`scripts/sandbox-check.js`. Nothing here is fabricated.

Generate a run:

```sh
PAYPAL_CLIENT_ID=... \
PAYPAL_CLIENT_SECRET=... \
SANDBOX_TEST_EMAIL=sb-buyer@business.example.com \
npm run sandbox:check
```

The script creates a sandbox invoice, sends it, reads it back from the
Invoicing API, sends a reminder, and writes a timestamped JSON file containing:

- the PayPal invoice id and status,
- the remote total and currency read back from PayPal,
- the `PayPal-Debug-Id` header for each call,
- the local audit-chain verification result.

It deliberately never records the client id, the secret, access tokens, or
request headers. Review the file before committing it.

If the run fails, the file still records the error name, code, and debug id so
the failure can be investigated. Do not edit a failing file to make it look
successful; fix the integration and generate a new run.

A committed evidence file is the only acceptable proof of a live sandbox run.
The automated tests use mocked PayPal responses and are labelled as such in the
README's live-vs-demo table.
