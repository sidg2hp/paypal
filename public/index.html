HOW IT WORKS

A trust loop you can see

Copilot recommends the move, keeps the decision human, and shows the proof.

Demo provenance: checking connection mode…
  1. ✦
    1. Agentic plan

    Copilot reads invoice status, due dates, payer history, and policy, then proposes a short ranked plan. It never invents an invoice id.

  2. AI
    2. Explainable signal

    Every recommendation includes its reason codes, confidence, the policy rule that allowed it, and the payer-adjusted expected date.

  3. ✓
    3. PayPal action

    You approve each step. The app creates/sends the invoice, sends a reminder, or creates a PayPal Checkout link through the configured adapter.

  4. ⌁
    4. Verified outcome

    In sandbox mode PayPal verifies webhook signatures. Every timeline event is SHA-256 hash-chained so the audit trail can be verified on demand.

✓ Human approval stays in the loop
